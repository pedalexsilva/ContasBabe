# **App Name**: GratitudeBloom

## Core Features:

- Customizable Reminders: Set flexible gratitude reminder times with options for silent notifications or calming sounds.
- Flexible Entry Options: Record daily reflections through text or voice memos, providing flexibility in how users express gratitude. The text entries will be saved as text; the voice memos will be available as audio records.
- Audio Transcription: Transcribe the audio input from voice memos into text using speech-to-text technology, with the possibility of editing the result.
- Guided Gratitude Prompts: Answer three daily gratitude prompts, chosen either as a fixed set or from a rotating question bank, with a hybrid option to include both.
- Interactive Gratitude Journal: Store daily entries in a journal format, accessible through a calendar view and searchable by keywords and tags. You can switch between viewing your entries (past gratitude moments) as audio, text, or both.
- Motivational Insights: Display streaks, milestones, and inspirational quotes to encourage consistent gratitude practice.

## Style Guidelines:

- Primary color: Soft lavender (#D0B4DE) to evoke calmness and reflection. The hue is reminiscent of twilight, aligning with themes of introspection.
- Background color: Light gray (#F0F0F4), providing a subtle, neutral backdrop that doesn't distract from the content.
- Accent color: Muted purple (#957DAD) to highlight key interactions and provide a gentle contrast, while remaining harmonious with the overall calming aesthetic.
- Clean, readable font optimized for journal entries and prompt displays.
- Simple line icons for navigation and feature representation.
- Subtle animations for positive reinforcement (e.g., a blooming flower when a journal entry is saved).
